# chaitanya-dwivedi.github.io

Personal academic and research homepage for **Chaitanya Dwivedi** (`https://chaitanya-dwivedi.github.io`).

## Quick Deploy to GitHub Pages

1. Create a public GitHub repository named **`chaitanya-dwivedi.github.io`** under the `chaitanya-dwivedi` GitHub account (`https://github.com/new`).
2. Push this directory:
   ```bash
   cd /Users/chaitanya.dwivedi/.gemini/antigravity/scratch/chaitanya-dwivedi.github.io
   git remote add origin git@github.com:chaitanya-dwivedi/chaitanya-dwivedi.github.io.git
   git push -u origin main
   ```
3. Optional headshot: place any square/portrait photo at `assets/headshot.jpg`, commit, and push—`index.html` automatically displays it in the top-right header.
